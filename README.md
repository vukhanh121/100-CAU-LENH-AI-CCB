# Thư viện 100 câu lệnh AI – Hội Cựu chiến binh phường Rạch Giá

Website tĩnh HTML/CSS/JavaScript, không cần backend hoặc API key. Toàn bộ 100 câu lệnh được trích từ tài liệu DOCX người dùng cung cấp.

## Chạy thử
Mở `index.html` bằng trình duyệt, hoặc chạy `python -m http.server 8000` trong thư mục này rồi mở `http://localhost:8000`.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub (hoặc sao lưu repository cũ trước khi thay thế).
2. Tải bốn file `index.html`, `style.css`, `script.js`, `data.js` lên thư mục gốc repository.
3. Vào Settings → Pages → Build and deployment → Deploy from a branch → chọn `main` và `/ (root)` → Save.
4. Đợi GitHub Pages xuất bản. URL thường là `https://TEN-TAI-KHOAN.github.io/TEN-REPOSITORY/`.

## Chỉnh sửa
- `data.js`: nội dung và tên 100 câu lệnh.
- `style.css`: màu sắc, cỡ chữ và bố cục.
- `index.html`: tên đơn vị, hướng dẫn, liên kết và thông tin chân trang.
- `script.js`: tìm kiếm, lọc, hộp thoại và sao chép.

Website không tự gửi dữ liệu đến ChatGPT/Gemini; người dùng chủ động sao chép và dán. Chưa triển khai trực tiếp lên địa chỉ website cũ.
